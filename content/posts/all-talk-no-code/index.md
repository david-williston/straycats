We live in a time of incredibly rich technology and very mature development tools. I think
the moment has come for something like this to exist. But it'll take time and resources,
and I'm **not going to start coding today**. For a while, this is going to be all talk.

That's on purpose. Writing code now would constrain the thinking. The most valuable work
right now is figuring out **what the system *is*** before deciding how software should
represent it.

So for now there's:

- no product plan
- no MVP
- no business model
- no commitments

Just following whichever question seems most interesting, and seeing where it leads. Along
the way I expect to uncover the [building blocks](/ideas/the-building-blocks/) the system
will need to understand.

## Why a blog, and why this one

I wanted somewhere to share these ideas and get feedback — and I wanted to **own the
platform completely**, rather than put it on Facebook or another algorithm-driven social
network. So this is a simple website of its own, with short posts and a way to
reply directly.

I'm not pitching an app here. Each post starts with something real — a cat, a name, a
caretaker, a vet bill, a disappearance — and follows the question it raises. If you
recognise the problem because you're living it too, you're exactly who I'd like to hear
from. The unfinished thinking is the interesting part.
